# Travel Management System

## Overview

The Travel Management System (TMS) is an internal web application designed to help organizations manage employee business travel from request submission to trip completion. The system supports travel requests, approval workflows, bookings, expense management, notifications, and reporting.

## Technologies used

- Backend: .NET 8 / ASP.NET Core Web API (C#)
- Data access: Entity Framework Core with Npgsql (PostgreSQL)
- Frontend: React (Create React App), JavaScript
- API client: Fetch-based wrapper (no axios)
- Authentication: JWT (development/demo credentials seeded)
- Containerization: Docker & Docker Compose
- Tooling: npm, node, dotnet CLI
